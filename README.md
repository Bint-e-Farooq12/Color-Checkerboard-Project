# Color Checkerboard Project

A checkerboard-style grid created using HTML table elements. This project demonstrates how rows, columns, cell attributes, and background colors can be combined to build a structured visual layout using HTML.

## About the Project

This project was developed during a live-class competition with a limited time to complete the assigned task. I completed the task first by applying my understanding of HTML table elements to create a recognizable checkerboard pattern.

The layout is built using table rows ("tr") and data cells ("td"). Alternating black and default-colored cells create the checkerboard effect, while HTML attributes define the cell dimensions and borders.

## Key Features

- Black-and-white checkerboard-style pattern
- Grid structure created with HTML table elements
- Alternating cell background colors
- Defined cell dimensions and borders
- Completed as part of a timed live-class challenge

## Technologies Used

- HTML5

## HTML Concepts Practiced

- Table structure using the "table", "tr", and "td" elements
- Organizing content into rows and columns
- Setting cell background colors
- Defining dimensions and borders through HTML attributes
- Creating a visual pattern using HTML table elements
